# Teams

One folder per team. Copy `_template/` and rename.

```
teams/
  _template/        <- copy this
  <team-name>/
    baseline.md     <- the numbers before you changed anything
    policies.md     <- this team's agreed policies (adapted from docs/04)
    log.md          <- running weekly log
    forecasts.md    <- every forecast, recorded when made
```

Keep the folders per **team**, not per project. The team is the system whose behaviour
you are trying to make predictable; projects pass through it.
